UI Modules

Komponen antarmuka yang memisahkan logika visual dari engine evaluasi.

Prinsip Desain UI: Semua komponen UI bersifat stateless sebisa mungkin. Mereka menerima data dari main.js atau state.js, merendernya, dan memanggil callback jika user berinteraksi. UI tidak pernah menyimpan data project secara langsung.

1. Code Editor (src/ui/editor.js)

Menggunakan pendekatan Textarea Overlay: ada <textarea> transparan di atas <pre> yang berisi syntax highlighting.

createEditor({ editorEl, highlightEl, gutterEl, onChange, ... })function
(options) → EditorAPI
Menginisialisasi editor. Mengembalikan API untuk mengontrol isi editor dan history (undo/redo).
setValue(value, { recordHistory })method
Mengganti seluruh teks di editor. Jika recordHistory=false (dipakai saat pindah tab), history akan di-reset.
toggleLineComment()method
Mengomentari/membuka komentar pada baris yang dipilih (// ). Jika semua baris terpilih sudah dikomentari, ia akan membuka komentarnya.
onValueChange(fn)method
Event listener untuk mendeteksi perubahan nilai (dipakai oleh Find/Replace dan Auto-format).

Fitur Editor Lainnya: Code Folding (melipat blok {...}), Multi-cursor (Ctrl+Click), dan History dengan debounce (agar Ctrl+Z tidak per huruf).

2. Console & Status (src/ui/console.js & status.js)

log(level, msg)function
(level: 'info'|'warn'|'error'|'ok', msg: string)
Menambahkan pesan ke panel console bawah. Memberi warna sesuai level (merah untuk error, kuning untuk warning) dan menaikkan badge counter.
setStatus(kind, text, showCancel)function
Mengubah indikator status di topbar (titik hijau = Ready, kuning berkedip = Rendering, merah = Error).
toast(msg)function
Menampilkan notifikasi melayang (muncul 2 detik lalu hilang). Digunakan untuk feedback seperti "💾 Saved" atau "⬇ Export OK".

3. Params Panel (src/ui/params-panel.js)

Panel dinamis yang di-generate dari anotasi // @param di dalam kode user.

createParamsPanel({ panelEl, bodyEl, onChange, ... })function
(options) → ParamsAPI
Membuat panel. Memetakan tipe data dari core/params.js ke elemen HTML: slider (input range), enum (select), color (input color), dan bool (checkbox).
setParams(params, values)method
Menerima array definisi parameter dan nilai saat ini, lalu merender ulang semua kontrol input.
setValue(name, value)method
Memperbarui UI slider secara silent (tanpa memicu ulang onChange). Digunakan oleh Param Animation saat menggerakkan slider.

4. Tab Bar (src/ui/tabbar.js)

render(tabs, activeId, callbacks)function
Merender daftar tab di bawah topbar. Mendukung fitur Double-click to Rename, tombol Close (×), dan tombol Add (+).

5. Modals & Dropdown

createCheatSheet(containerEl)function
Modal referensi syntax dan shortcut (muncul saat tekan ?). Memiliki fitur pencarian (filter real-time) untuk mencari fungsi seperti cube atau rotate.
createDropdown({ container, items, onSelect })function
Komponen dropdown custom. Menggunakan position: fixed agar tidak terpotong oleh overflow: hidden pada parent-nya (masalah umum di topbar yang scrollable).
createHomeScreen(containerEl, callbacks)function
Layar sambutan awal (New Project, Import STL, Load ZIP). Menampilkan grid file STL yang tersimpan di IndexedDB (maksimal 5 file).

6. Find/Replace & Profiler

createFindReplace({ editorEl, containerEl, ... })function
Bar pencarian (Ctrl+F). Mendukung pencarian case-sensitive (Aa), whole word (W), dan Replace/Replace All. Menampilkan highlight kuning pada textarea overlay.
createProfilerPanel(panelEl)function
Menampilkan metrik render (Current, History, Hotspots). Sangat membantu developer untuk melihat bagian mana dari kode yang memakan waktu paling lama (misal: operasi difference 500ms).
