Core — Tokenizer, Parser & Scope

Lapisan parsing bahasa. Semua fungsi di sini murni (tanpa DOM).

Alur Evaluasi

source (string) └─ tokenize() → tokens[] └─ Parser.parseProgram() → AST ├─ applyParams() → AST dengan nilai param └─ evalStatements() → geometry (evaluator.html)

1. Tokenizer & Parser

tokenize(src)function
src: string → Token[]
Mengubah string kode menjadi deretan token. Mendukung:
  • Angka (termasuk notasi ilmiah 1e-3), String, Identifier (termasuk $vars).
  • Komentar (// dan /* */).
  • Modifier: * (disable), ! (show only), # (highlight), % (background).
  • Raw string untuk include <file.scad>.
Parser.parseProgram()class method
() → { type: 'Program', body: AST[] }
Fungsi utama yang memanggil parseStatement() secara berulang hingga akhir file (EOF).
parseStatement()method
Mendeteksi jenis statement berdasarkan token pembuka:
  • module, function
  • if, for, intersection_for (baru)
  • include, use
  • Assignment (x = 10;)
  • Module call (cube(10);)
parsePrimary()method
Menangani ekspresi dasar. Fitur Baru: Mendukung pembacaan Anonymous Function (function(x) x*2) secara langsung sebagai ekspresi.
parseComprehensionBody()method
Menangani isi dari List Comprehension [ ... ]. Fitur Baru: Mendukung kata kunci each untuk meratakan (flatten) array hasil loop.

2. Struktur AST (Abstract Syntax Tree)

Node yang dihasilkan oleh Parser dan dikonsumsi oleh Evaluator.

Node Type Bidang Penting Contoh Kode
ModuleCall name, args, children cube(10);
For iterators, body for(i=[0:5]) ...
IntersectionFor iterators, body intersection_for(i=[0:5]) ...
If cond, thenBody, elseBody if (x) ... else ...
AnonymousFunction params, expr f = function(x) x*2;
ListComp kind ('for'|'if'|'expr'|'each'), ... [for(i) each [i,i]]
Let / LetStatement bindings, body/expr let(a=1) ...
Ternary cond, thenExpr, elseExpr x > 0 ? 1 : 0

3. Scope & Params

class Scope(parent)class
Menyimpan variabel (Map), module, function, dan childrenContext. Menggunakan rantai prototype (parent) untuk mencari variabel dari scope terdalam ke terluar.
parseParams(code)function
Membaca komentar // @param atau format OpenSCAD Customizer ([min:max]) untuk menghasilkan array definisi UI (slider, enum, bool).
