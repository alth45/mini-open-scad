Worker & Model

Bagaimana kode dievaluasi di background thread dan dikirim kembali ke UI secara efisien.

Zero-Copy Transfer: Untuk mencegah UI freeze saat merender model berat, evaluasi dan pembentukan mesh dilakukan di Web Worker. Data dikirim kembali menggunakan Transferable Objects (Float32Array buffer) agar proses pemindahan data berlangsung instan tanpa menduplikasi memori.

1. Worker Client (src/worker/worker-client.js)

Berjalan di Main Thread (UI). Bertugas membuat Worker baru untuk setiap render, mengirim perintah, dan menangani timeout.

createWorkerClient()function
() → { run, cancel, dispose }
Membuat instance wrapper. Menggunakan new Worker(new URL('./eval-worker.js', import.meta.url), { type: 'module' }) agar kompatibel dengan Vite bundling.
run(code, paramValues, previewMode)method
(string, object, boolean) → Promise<WorkerResponse>
Mengirim job ke Worker. Fitur penting:
  • Cancel Pending: Jika dipanggil lagi saat render sebelumnya belum selesai, render lama akan di-terminate dan dilempar error CancelledError.
  • Watchdog: Memasang timer timeout (65 detik). Jika Worker tidak membalas, proses dihentikan paksa.
  • Ready Handshake: Menunggu sinyal { type: 'ready' } dari Worker sebelum mengirim data (mencegah race condition).
Dipanggil oleh:
doRender (main.js)

2. Eval Worker (src/worker/eval-worker.js)

Berjalan di Background Thread. Tidak memiliki akses ke DOM.

self.onmessageevent handler
(e: MessageEvent) → void
Menerima instruksi dari Main Thread. Alur kerjanya:
  1. await preloadOpenTypeFonts(): Memuat font Jepang (CJK).
  2. await initManifold(): Memuat engine WebAssembly Manifold-3D.
  3. await loadFiles(importNames): Mengambil file STL dari IndexedDB.
  4. Memanggil buildModel() dari `viewer/model.js`.
  5. postMessage(response, transferables): Mengembalikan hasil.

3. Build & Serialize (src/viewer/model.js)

Jembatan antara evaluator (yang menghasilkan objek Three.js) dengan Web Worker (yang harus mengirim data murni).

buildModel(code, paramValues, files, previewMode, scadCache)function
(...) → { root, meshes, shapes2d, warnings, ... }
Orkestrator utama di dalam Worker. Menjalankan: tokenize → parseProgram → applyParams → evalStatements. Setelah itu, memisahkan hasil 3D (root) dan 2D (shapes2d), lalu memanggil serializeModel().
Memanggil:
evalStatementsserializeModel
serializeModel(root)function
root: THREE.Group → Array<{ positions, normals, color }>
Flatten objek 3D menjadi array data mentah.
  • Menerapkan applyMatrix4(matrixWorld) agar posisi absolute tersimpan.
  • Mengubah geometri ber-index menjadi Non-Indexed (Triangle Soup).
  • Mendeteksi mirror (determinant < 0) dan membalik urutan vertex (winding order) jika perlu.
  • Menyimpan warna material per-mesh.
Dipanggil oleh:
buildModel
deserializeModel(meshes)function
meshes: Array → THREE.Group
Kebalikan dari serializeModel. Berjalan di Main Thread setelah data diterima dari Worker. Membuat ulang BufferGeometry, menghitung ulang normal jika tidak ada, dan mengaplikasikan MeshStandardMaterial dengan warna yang sesuai.
Dipanggil oleh:
doRender (main.js)
Perhatian: Jangan pernah mengirim objek THREE.Mesh secara langsung melalui postMessage! Objek tersebut tidak bisa di-clone oleh browser, dan referensi memori (WebGL context) tidak bisa dibagikan antar thread. Selalu gunakan serializeModel().
