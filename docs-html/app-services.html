App, Storage & Services

Logika aplikasi utama, fitur UI modular, mesin eksportir, dan persistensi data.

Arsitektur Modular: main.js tidak lagi memuat semua kode. Fitur-fitur UI dipisah ke dalam folder src/app/, sehingga main.js hanya bertugas sebagai Orchestrator (menginisialisasi dan menghubungkan modul).

1. Core Orkestrator (src/main.js)

doRender(opts)async function
({ skipParams, skipFit, quiet, throwOnError }) → Promise<void>
Fungsi utama yang dipanggil setiap kali user menekan Render atau mengubah slider. Mengambil kode dari editor, mengirimkannya ke workerClient.run(), lalu merender hasilnya ke Viewer. Juga menangani pencatatan waktu ke Profiler dan menampilkan pesan ke Console.
saveNow() / scheduleSave()function
Menyimpan seluruh tab yang terbuka ke localStorage. scheduleSave menggunakan debounce 500ms agar tidak terlalu sering menulis ke disk.

2. App Modules (src/app/)

Kumpulan modul yang menginisialisasi fitur UI. Semuanya menerima dependensi (seperti viewer atau editor) sebagai parameter.

initShortcuts(deps)function
(deps: object) → void
Mendaftarkan semua event listener keyboard (Capture Phase). Menangani Ctrl+Enter (Render), Ctrl+S (Save), F5/F6 (Preview/Render), Esc (Tutup modal/Cancel render), dan shortcut lainnya.
initViewerTools(viewer)function
Menyuntikkan tombol dan panel ke viewport 3D: Camera Presets (ISO/FRT/TOP), Fullscreen, Dimensions, Section Plane, dan Measure Tool.
initCapture(deps)function
Menangani fitur Screenshot PNG, Turntable GIF, dan Param Animation (preview live dan ekspor animasi ke GIF).
initExportUI(deps)function
Membangun dropdown Export dan menangani pemanggilan fungsi eksportir (STL, 3MF, OBJ, DXF, SVG, dll) serta tombol Save Project (.zip).

3. Exporters (3D & 2D)

Mesin yang mengubah objek Three.js menjadi file fisik.

Export 3D (src/export.js)

exportSTL(modelRoot)function
Ekspor mesh ke format STL (binary). Karena hasil dari Manifold sudah watertight, file STL dijamin bebas dari error non-manifold.
export3MF(modelRoot)function
Ekspor ke format 3MF (ZIP+XML). Dilengkapi dengan weld vertices (mergeVertices) sebelum ditulis ke XML, memastikan tidak ada triangle soup. Mendukung metadata warna (walau PrusaSlicer memiliki keterbatasan).

Export 2D (src/export-2d.js)

exportSVG(shapes2d) / exportDXF(shapes2d)function
Menerima array kontur 2D (hasil ekstraksi Manifold 2D dari engine), lalu menggambarnya sebagai vektor garis. Sangat cocok untuk Laser Cutting atau CNC.
Memanggil:
state.last2dShapes (dari model.js)

4. Storage & Backup

saveTabs / loadTabsfunction
Menyimpan array tab (kode, parameter, nama) ke localStorage. Mendukung migrasi dari format v1 (single project) ke v2 (multi-tab).
exportProjectZip(tab)async function
(tab) → Promise<{ name, size }>
Membuat file ZIP berisi project.json (kode + parameter) dan folder files/ yang berisi semua file STL/SCAD yang diimpor di project tersebut. Menggunakan library fflate.
importProjectZip(arrayBuffer)async function
Mengekstrak ZIP, membaca project.json, dan me-restore semua file STL yang ada di dalamnya kembali ke IndexedDB.

5. Share via URL

encodeShareTab(tab)async function
Mengompresi kode dan parameter tab menjadi string Base64 URL-safe. Menggunakan CompressionStream('gzip') bawaan browser (dengan fallback ke JSON biasa jika browser tidak mendukung).
readShareFromUrl()async function
Membaca hash URL (#s=...). Jika ada, akan mendekode project dan memuatnya sebagai tab baru saat aplikasi dibuka.
