App, Storage & Services

Logika aplikasi utama, fitur UI modular, mesin eksportir, dan persistensi data.

Arsitektur Modular: main.js tidak lagi memuat semua kode. Fitur-fitur UI dipisah ke dalam folder src/app/, sehingga main.js hanya bertugas sebagai Orchestrator (menginisialisasi dan menghubungkan modul).

1. Core Orkestrator (src/main.js)

doRender(opts)async function
({ skipParams, skipFit, quiet, throwOnError }) → Promise<void>
Fungsi utama yang dipanggil setiap kali user menekan Render atau mengubah slider. Mengambil kode dari editor, mengirimkannya ke workerClient.run(), lalu merender hasilnya ke Viewer. Juga menangani pencatatan waktu ke Profiler dan menampilkan pesan ke Console.
saveNow() / scheduleSave()function
Menyimpan seluruh tab yang terbuka ke localStorage. scheduleSave menggunakan debounce 500ms agar tidak terlalu sering menulis ke disk.

2. App Modules (src/app/)

Kumpulan modul yang menginisialisasi fitur UI. Semuanya menerima dependensi (seperti viewer atau editor) sebagai parameter.

initShortcuts(deps)function
(deps: object) → void
Mendaftarkan semua event listener keyboard (Capture Phase). Menangani Ctrl+Enter (Render), Ctrl+S (Save), F5/F6 (Preview/Render), Esc (Tutup modal/Cancel render), dan shortcut lainnya.
initViewerTools(viewer)function
Menyuntikkan tombol dan panel ke viewport 3D: Camera Presets (ISO/FRT/TOP), Fullscreen, Dimensions, Section Plane, Measure Tool, dan Lighting Presets (Studio/Dramatic).
initCapture(deps)function
Menangani fitur Screenshot PNG, Turntable GIF, dan Param Animation (preview live dan ekspor animasi ke GIF).
initExportUI(deps)function
Membangun dropdown Export dan menangani pemanggilan fungsi eksportir (STL, 3MF, OBJ, DXF, SVG, dll) serta tombol Save Project (.zip).

3. Exporters (3D & 2D)

Mesin yang mengubah objek Three.js menjadi file fisik.

Export 3D (src/export.js)

exportSTL / OBJ / GLTF / PLYfunction
Fungsi ekspor standar. Karena hasil dari Manifold sudah watertight, file yang dihasilkan dijamin bebas dari error non-manifold.
export3MF(modelRoot)function
Ekspor ke format 3MF (ZIP+XML). Dilengkapi dengan weld vertices (mergeVertices) sebelum ditulis ke XML, memastikan tidak ada triangle soup. Mendukung metadata warna standar 3MF, meskipun beberapa Slicer (seperti PrusaSlicer) memiliki keterbatasan dalam membaca warna eksternal.

Export 2D (src/export-2d.js)

exportSVG(shapes2d) / exportDXF(shapes2d)function
Menerima array kontur 2D (hasil ekstraksi Manifold 2D dari engine), lalu menggambarnya sebagai vektor garis. Sangat cocok untuk Laser Cutting atau CNC.
Memanggil:
state.last2dShapes (dari model.js)

4. Storage & Backup

saveTabs / loadTabsfunction
Menyimpan array tab (kode, parameter, nama) ke localStorage. Mendukung migrasi dari format v1 (single project) ke v2 (multi-tab).
exportProjectZip(tab)async function
(tab) → Promise<{ name, size }>
Membuat file ZIP berisi project.json (kode + parameter) dan folder files/ yang berisi semua file STL/SCAD yang diimpor di project tersebut. Menggunakan library fflate.
importProjectZip(arrayBuffer)async function
Mengekstrak ZIP, membaca project.json, dan me-restore semua file STL yang ada di dalamnya kembali ke IndexedDB.

5. Share via URL

encodeShareTab(tab)async function
Mengompresi kode dan parameter tab menjadi string Base64 URL-safe. Menggunakan CompressionStream('gzip') bawaan browser (dengan fallback ke JSON biasa jika browser tidak mendukung).
readShareFromUrl()async function
Membaca hash URL (#s=...). Jika ada, akan mendekode project dan memuatnya sebagai tab baru saat aplikasi dibuka.

6. Cloud Backup & Sync (src/files/cloud-storage.js)

Backup snapshot per tab ke Cloudinary (unsigned upload — tidak ada secret di bundle). Setiap save = file baru dengan timestamp; index versi disimpan di localStorage (maks 20 versi/tab).

backupTab(tab)async function
(tab) → Promise<{ codeUrl, metaUrl, size, deleteToken }>
Mengupload snapshot tab (kode gzip + meta + presets) ke Cloudinary. Menggunakan upload_preset (unsigned), sehingga tidak membutuhkan API key di bundle.
restoreFromUrls(params)async function
({ url } | { codeUrl, metaUrl }) → Promise<tabData>
Mengembalikan tab dari URL Cloudinary. Mendukung format gabungan (JSON dengan code terkompresi) dan format legacy (2 file terpisah). Hasilnya dibuat sebagai tab baru, tidak menimpa tab aktif.
deleteByToken(deleteToken)async function
(token: string) → Promise<{ ok, error? }>
Menghapus file di Cloudinary melalui delete_token (valid 10 menit setelah upload). Setelah itu, hapus manual di dashboard Cloudinary.
exportBackupBundle()function
Mengekspor seluruh riwayat backup sebagai file JSON untuk dipindahkan antar device.
importBackupBundle(jsonText)function
(jsonText: string) → { merged, totalTabs }
Mengimpor bundle backup dan merge ke index lokal.
Keamanan: Tidak ada API key di bundle. Upload pakai upload_preset Cloudinary (unsigned). Setiap upload = file baru dengan public_id ber-timestamp, tidak overwrite.

7. Preset Parameter per Tab (src/files/preset-store.js)

IndexedDB (mini-openscad-presets) menyimpan daftar preset parameter ({name, values, createdAt, updatedAt}) per tabId. Preset ikut disertakan dalam cloud backup snapshot dan dapat dipulihkan bersama tab.

loadPresets(tabId)async function
(tabId: string) → Promise<Array<{name, values, createdAt, updatedAt}>>
Memuat daftar preset parameter untuk tab tertentu.
savePresets(tabId, presets)async function
(tabId: string, presets: Array) → Promise<void>
Menyimpan daftar preset parameter untuk tab tertentu.
deleteAllPresets(tabId)async function
(tabId: string) → Promise<void>
Menghapus semua preset untuk tab tertentu.

8. Token Tracker AI (src/ai/token-tracker.js)

Mencatat setiap request AI di localStorage (mini-openscad-ai-stats) untuk rate limit dan estimasi biaya.

recordRequest(opts)function
({ inputTokens, outputTokens, model }) → void
Mencatat satu request AI: timestamp, token in/out, biaya estimasi, dan breakdown per hari.
getRateLimitCounts()function
() → { perMin, perHour, limits }
Menghitung jumlah request dalam window 60 detik dan 3600 detik (rolling window).
snapshot()function
() → { rate, total, byDay }
Mengembalikan ringkasan statistik untuk ditampilkan di UI (token-widget).
resetStats()function
Mengatur ulang semua statistik AI ke default.
Rate limit: 60 request/menit, 1800 request/jam (TokenHarbor free tier). Penyimpanan rolling window 60s / 3600s; breakdown per hari (30 hari terakhir).

9. PWA & Offline (src/app/pwa.js)

Aplikasi terinstall sebagai PWA dengan service worker, tombol install, dan indikator online/offline.

initPWA(deps)function
({ toast, log }) → void
Mendaftarkan service worker (vite-plugin-pwa), menampilkan tombol Install, banner update versi baru, dan indikator online/offline. Cek update SW setiap jam.

10. Mobile UI (src/app/mobile-ui.js)

Peningkatan antarmuka untuk layar kecil (≤ 768px).

initMobileUI(deps)function
({ viewer }) → void
Memperbaiki tab bar Code/3D/Console pada mobile. Membuat menu "More" (⋮) yang memindahkan tombol jarang dipakai (Format, Export, Preset, Snippet, dll.) ke dalam panel dropdown.

11. Import SVG/DXF (src/app/import-vector-ui.js)

Konversi file vektor (SVG/DXF) menjadi kode SCAD yang bisa dimasukkan ke editor.

initImportVectorUI(deps)function
({ editor, tabManager, saveNow, doRender }) → { open, processFile }
Membuka modal import, memproses file SVG/DXF melalui svg-to-polygon.js / dxf-to-polygon.js, lalu mengonversi hasilnya ke kode SCAD dengan vector-to-code.js.
svgToPolygon(svgText)function
(svgText: string) → Polygon[]
Mengekstrak kontur poligon dari teks SVG.
dxfToPolygon(dxfText)function
(dxfText: string) → Polygon[]
Mengekstrak kontur poligon dari teks DXF.
vectorToCode(polygons)function
(polygons: Polygon[]) → string
Mengonversi array poligon menjadi kode SCAD (polygon(...)).
