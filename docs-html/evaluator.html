Evaluator & Builtins

Lapisan yang mengeksekusi AST menjadi objek 3D (Mesh/Group) atau objek 2D (Shape).

Pure Functions: Semua fungsi di sini tidak menyentuh DOM. Output-nya murni berupa struktur data yang nantinya akan diserialisasi oleh Worker untuk dikirim ke Main Thread.

1. Evaluator Core (src/evaluator/index.js)

evalStatements(stmts, scope, ctx)function
stmts: AST[], scope: Scope, ctx: EvalContext → Object3D[]
Menjalankan array statement. Menangani modifier, block {}, serta mendeteksi infinite recursion.
evalExpr(node, scope, ctx)function
node: AST, scope: Scope, ctx: EvalContext → any
Mengevaluasi ekspresi matematika/logika. Fitur Baru:
  • Index: Mendukung akses string (misal "Halo"[1] mengembalikan "a").
  • AnonymousFunction: Mengembalikan objek fungsi dengan closure ke scope saat ini.
  • Var: Jika variabel tidak ditemukan, mengembalikan undef (null) dan mengirim warning, bukan error yang menghentikan render.
evalCall(node, scope, ctx)function
Mengeksekusi pemanggilan fungsi. Mencari fungsi dengan urutan:
  1. User-defined function (function foo())
  2. Anonymous function (f = function())
  3. Builtin function (sin, rands, dll)

2. EvalContext (Timeout & Warning)

Objek ctx yang dilempar ke setiap fungsi evaluator.

  • ctx.check(): Dipanggil secara berkala (terutama di dalam loop) untuk mengecek batas waktu ($maxTime).
  • ctx.warn(msg): Mencatat warning unik untuk ditampilkan di console UI.
  • ctx.trackOp(name, fn): Mencatat waktu eksekusi tiap builtin (untuk fitur Profiler).

3. Builtins 3D & 2D (src/evaluator/builtins.js)

cube / sphere / cylinder / polyhedronbuiltins
Primitif 3D standar. Mengembalikan array THREE.Mesh.
circle / square / polygon / textbuiltins
Primitif 2D. Mengembalikan objek { __shape2d: true, shapes: THREE.Shape[] }. Fitur Baru: polygon mendeteksi jika garis saling menyilang dan memunculkan warning.
render(a, node, scope, ctx)builtin
Kompatibilitas OpenSCAD. Karena engine kita selalu menggunakan Manifold (selalu di-render), fungsi ini hanya meneruskan child-nya tanpa operasi tambahan.

4. Boolean (CSG) & Intersection For

Menggunakan engine Manifold (jika tersedia) atau fallback ke three-bvh-csg.

union / difference / intersectionbuiltins
Jika input adalah 2D (__shape2d), engine akan melakukan trik: mengekstrusi 0.1mm, menjalankan CSG 3D Manifold, lalu mengekstrak kontur luarnya kembali menjadi 2D.
intersectObjects(kids, node, scope, ctx)helper
Fitur Baru: Fungsi publik yang menerima array objek. Digunakan oleh intersection() dan diekspos agar intersection_for di index.js bisa memanggilnya secara langsung.

5. Extrusions & Twist

linear_extrudebuiltin
Fitur Baru: Mendukung parameter twist dan scale. Karena Three.js tidak mendukung ini secara native, kita membuat fungsi kustom createTwistedExtrusion() yang membangun geometri secara manual layer-per-layer, lalu menghitung vertex normalnya.
rotate_extrudebuiltin
Memutar 2D Shape mengelilingi sumbu Z (menggunakan THREE.LatheGeometry).
offset / minkowski / hullbuiltins
Operasi geometri lanjutan. Hull menggunakan Manifold.hull() (jika tersedia) untuk presisi maksimal.

6. Modifiers (# & %)

applyModifier(objs, modifier)function
Fitur Baru: Menerapkan sifat transparan ke objek.
  • # (Highlight): Warna Pink, opacity 60%.
  • % (Background): Warna Abu-abu, opacity 20%. Objek ini juga ditandai (userData.isBackground = true) agar tidak ikut dieksport ke STL/3MF.

Fungsi murni matematika & data.

Kategori Fungsi

Dasar abs, sign, sqrt, pow, exp, ln, log
Array / Data min, max, len, norm, concat, str
Vektor cross (baru)
Utilitas rands (baru), chr (baru), ord (baru), search (baru)
Tipe Data (is_*) is_num, is_string, is_bool, is_list, is_undef, is_function, is_range, is_object
