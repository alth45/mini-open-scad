Evaluator & Builtins

Lapisan yang mengeksekusi AST menjadi objek 3D (Mesh/Group) atau objek 2D (Shape).

Pure Functions: Semua fungsi di sini tidak menyentuh DOM. Output-nya murni berupa struktur data yang nantinya akan diserialisasi oleh Worker untuk dikirim ke Main Thread.

1. Evaluator Core (src/evaluator/index.js)

evalStatements(stmts, scope, ctx)function
stmts: AST[], scope: Scope, ctx: EvalContext → Object3D[]
Menjalankan array statement. Menangani modifier (*, !), block {}, serta mendeteksi infinite recursion (stack overflow).
Dipanggil oleh:
buildModelbuiltins (children)
evalExpr(node, scope, ctx)function
node: AST, scope: Scope, ctx: EvalContext → any
Mengevaluasi ekspresi matematika/logika. Mendukung literal, vektor, range [0:10], ternary ? :, list comprehension for, akses index [], dan pemanggilan fungsi.

2. EvalContext (Timeout & Warning)

Objek ctx yang dilempar ke setiap fungsi evaluator.

  • ctx.check(): Dipanggil secara berkala (terutama di dalam loop) untuk mengecek batas waktu ($maxTime). Melempar error jika waktu habis.
  • ctx.warn(msg): Mencatat warning unik (tidak duplikat) untuk ditampilkan di console UI.
  • ctx.echo(msg): Menyimpan output untuk dirender di console.
  • ctx.trackOp(name, fn): Mencatat waktu eksekusi tiap builtin (untuk fitur Profiler).

3. Builtins 3D (src/evaluator/builtins.js)

Semua modul di bawah ini mengembalikan array berisi THREE.Mesh atau THREE.Group.

cube(a, node, scope, ctx)builtin
size: number|[x,y,z], center: boolean
Membuat BoxGeometry. Jika center=false (default), objek digeser agar sudut bottom-left bertemu di origin (0,0,0).
sphere(a, node, scope, ctx)builtin
r: number, d: number, $fn: number
Membuat SphereGeometry. Resolusi segmen dihitung otomatis menggunakan fungsi helper getFnFor.
cylinder(a, node, scope, ctx)builtin
h: number, r1: number, r2: number, center: boolean
Membuat CylinderGeometry (Z-up). Secara default berdiri di atas origin (z=0).

4. Builtins 2D

Modul ini tidak mengembalikan Mesh, melainkan objek khusus { __shape2d: true, shapes: THREE.Shape[] }.

polygon(a, node, scope, ctx)builtin
points: [x,y][]
Membuat Shape dari kumpulan titik. Fitur Baru: Fungsi ini mendeteksi jika garis saling menyilang (self-intersecting) dan memunculkan ctx.warn() agar user waspada.
text(a, node, scope, ctx)builtin
text: string, size: number, font: string, halign, valign
Menghasilkan text 2D. Mendukung font Latin (helvetiker) dan deteksi otomatis CJK/Jepang (noto-jp) yang dimuat via opentype.js.

5. Transforms

Fungsi yang mengubah posisi/rotasi/ukuran child-nya. Jika child-nya 2D, transformasi diaplikasikan ke titik-titik Vector2.

translate / rotate / scale / mirror / multmatrixbuiltins
Menggunakan applyMatrixToChildren(). Membuat matriks THREE.Matrix4 baru, lalu menerapkannya ke Group atau Shape 2D.

6. Boolean (CSG) — Manifold Integration

Ini adalah operasi paling berat. Penting: Jika objek adalah 2D (Shape), engine akan mengonversinya ke 3D setipis 0.1mm, memprosesnya dengan Manifold, lalu mengekstrak garis luarnya kembali menjadi 2D.

union / difference / intersectionbuiltins
  • Manifold Ready: Menggunakan objToManifold() → result.add() / .subtract() / .intersect() → manifoldMeshToGeo().
  • Color Preserve: Mengambil material dari objek pertama (kids[0]) dan menerapkannya ke hasil akhir.
  • Fallback: Jika WASM gagal, menggunakan three-bvh-csg (hasil mungkin tidak watertight).
hull(a, node, scope, ctx)builtin
Jika Manifold aktif, menggunakan wasm.Manifold.hull() (presisi tinggi). Fallback ke ConvexGeometry Three.js.

7. Extrusions & Offset

linear_extrude / rotate_extrudebuiltins
Mengubah 2D THREE.Shape menjadi 3D ExtrudeGeometry atau LatheGeometry. Resolusi kurva diatur otomatis berdasarkan $fn.
offset(a, node, scope, ctx)builtin
Jika 2D, melakukan polygon offsetting manual. Jika 3D, menggunakan metode Minkowski Sum (menambahkan vertex objek ke vertex bola/kubus).

8. Math Functions (src/evaluator/functions.js)

Fungsi murni matematika untuk ekspresi OpenSCAD (contoh: sin(30), min(1,2)).

  • sin/cos/tan/asin/acos/atan/atan2 — Sudut dalam derajat (bukan radian).
  • abs/sign/sqrt/pow/exp/ln/log — Fungsi matematika standar.
  • floor/ceil/round — Pembulatan.
  • min/max — Menerima argumen terpisah atau array.
  • len/norm/concat/str — Manipulasi array/string.
