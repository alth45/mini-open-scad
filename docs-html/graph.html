Peta Ketergantungan (Call Graph)

Bagaimana setiap modul saling terhubung dalam arsitektur Mini OpenSCAD.

Prinsip Modularitas: Aplikasi ini sengaja dipisahkan menjadi dua dunia: Main Thread (UI, DOM, Render 3D) dan Worker Thread (Murni matematika, Parsing, CSG Manifold). Keduanya hanya berkomunikasi lewat postMessage.

1. Main Thread (UI & Orkestrasi)

Alur impor di main.js. Tanda panah (→) berarti "mengimpor/menggunakan".

main.js (Orkestrator) ├─ app/shortcuts.js (Mendaftarkan event keyboard global) ├─ app/viewer-tools.js (Kamera, Section, Measure, Dims) ├─ app/capture.js (PNG, Turntable GIF, Param Anim) ├─ app/export-ui.js (Dropdown Export & Save Project) │ ├─ viewer/scene.js (Class Viewer: WebGL, Lights, Raycaster) ├─ ui/editor.js (Textarea overlay, folding, multi-cursor) ├─ ui/params-panel.js (Render slider @param) ├─ ui/tabbar.js, home.js, etc (Modal & antarmuka) │ └─ worker/worker-client.js (Jembatan ke Worker)

2. Worker Thread (Engine CAD)

Alur yang berjalan di background saat tombol Render ditekan.

worker/eval-worker.js (Menerima postMessage) ├─ evaluator/manifold-engine.js (Memuat WASM) ├─ viewer/model.js (buildModel) │ ├─ core/tokenizer.js (String → Token) │ ├─ core/parser.js (Token → AST) │ ├─ evaluator/index.js (AST → Mesh/Shape) │ │ ├─ evaluator/builtins.js (cube, difference, dll) │ │ │ ├─ evaluator/manifold-engine.js (CSG 3D/2D) │ │ │ └─ evaluator/geometry.js (Helper Three.js) │ │ └─ evaluator/functions.js (sin, cos, min, dll) │ └─ viewer/model.js (serializeModel → transferables) └─ postMessage(data, transferables) → Kembali ke Main Thread

3. Peta Modul UI (src/app/)

Modul-modul ini dibuat agar main.js tidak menjadi "God Object" (terlalu besar).

ModulBergantung PadaFungsi Utama
shortcuts.js editor, findReplace, cheatSheet, animation Menangani semua tombol Ctrl, F5, Esc.
viewer-tools.js viewer, state Menyuntikkan tombol Fullscreen, View Presets, dan Section ke DOM.
capture.js viewer, gifenc, editor Merekam layar (PNG/GIF) dan menggerakkan slider otomatis.
export-ui.js export.js, export-2d.js, project-backup.js Membangun dropdown dan memanggil fungsi download.

4. Alur Data Export (3D & 2D)

Bagaimana model dari Viewer bisa menjadi file yang bisa dibuka di Slicer / AutoCAD.

app/export-ui.js (Klik User) │ ├─ Export 3D (STL/3MF/OBJ/GLB/PLY) │ └─ export.js │ ├─ memanggil viewer.modelRoot (Mesh dari Manifold) │ ├─ menggunakan mergeVertices (khusus 3MF) │ └─ memicu downloadBlob() │ ├─ Export 2D (SVG/DXF) │ └─ export-2d.js │ ├─ membaca state.last2dShapes (Kontur 2D hasil ekstraksi Manifold) │ └─ menulis string XML (SVG) atau string DXF R12 │ └─ Save Project (.zip) └─ project-backup.js ├─ membaca tabManager.active ├─ mengambil file STL dari files/file-store.js (IndexedDB) └─ membungkusnya dengan fflate (zipSync)
