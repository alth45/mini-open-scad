Peta Ketergantungan (Call Graph)

Bagaimana setiap modul saling terhubung dalam arsitektur Mini OpenSCAD.

Prinsip Modularitas: Aplikasi ini sengaja dipisahkan menjadi dua dunia: Main Thread (UI, DOM, Render 3D) dan Worker Thread (Murni matematika, Parsing, CSG Manifold). Keduanya hanya berkomunikasi lewat postMessage.

3. Peta Modul UI (src/app/)

Modul-modul ini dibuat agar main.js tidak menjadi "God Object" (terlalu besar).

Modul Bergantung Pada Fungsi Utama
shortcuts.js editor, findReplace, cheatSheet, animation Menangani semua tombol Ctrl, F5, Esc.
viewer-tools.js viewer, state Menyuntikkan tombol Fullscreen, View Presets, Section, dan Lighting ke DOM.
capture.js viewer, gifenc, editor Merekam layar (PNG/GIF) dan menggerakkan slider otomatis (Animation).
export-ui.js export.js, export-2d.js, project-backup.js Membangun dropdown dan memanggil fungsi download.
cloud-backup-ui.js cloud-storage.js, preset-store.js, tabManager Panel backup/restore Cloudinary per tab.
pwa.js vite-plugin-pwa, toast, log Service worker, install prompt, offline indicator.
mobile-ui.js viewer, DOM tabbar Menu More (⋮) untuk layar ≤ 768px.
preset-ui.js preset-store.js, tabManager, editor Panel preset parameter per tab.
import-vector-ui.js svg-to-polygon.js, dxf-to-polygon.js, vector-to-code.js Import SVG/DXF → kode SCAD.
