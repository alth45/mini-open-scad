Viewer 3D

Mengelola render scene, pencahayaan PBR, interaksi kamera, dan fitur CAD interaktif.

Class `Viewer`: Seluruh logika rendering dibungkus dalam satu class ini. Modul lain (seperti `app/viewer-tools.js`) hanya berkomunikasi dengan class ini melalui *public methods* yang sudah disediakan.

1. Inisialisasi & Kamera

Class Viewer dibuat sekali di `main.js` saat aplikasi dimuat.

new Viewer(container)constructor
(container: HTMLElement)
Menginisialisasi:
  • WebGLRenderer: Dengan Antialias, Tone Mapping ACESFilmic, dan Local Clipping aktif.
  • Kamera: PerspectiveCamera (FOV 45) dengan sumbu Z sebagai Up (standar CAD).
  • OrbitControls: Damping aktif untuk pergerakan kamera yang halus.
setView(preset)method
(preset: 'iso'|'front'|'right'|'top'|'back'|'left'|'bottom')
Mengubah posisi kamera ke sudut pandang tertentu. Menyesuaikan camera.up agar tidak terjadi gimbal lock (misal pada Top/Bottom view).
Dipanggil oleh:
app/viewer-tools.js (View Presets)
fitToObject(object)method
Menghitung Bounding Box dari objek, lalu memundurkan/maju kan kamera agar seluruh objek pas di layar (auto-framing).

2. Lighting & Theme

Fitur "Studio Look" yang membuat hasil render terlihat profesional.

setLightingPreset(preset)method
(preset: 'default'|'studio'|'dramatic')
  • Default: Cepat, tanpa bayangan, menggunakan Hemisphere & Directional light.
  • Studio: Menggunakan RoomEnvironment (PMREM) untuk pantulan PBR realistis, plus Soft Shadows di lantai.
  • Dramatic: Kontras tinggi dengan aksen cahaya biru.
Dipanggil oleh:
app/viewer-tools.js (Lighting Dropdown)
setTheme(theme)method
Mengubah warna background, grid helper, dan memicu render ulang warna wireframe jika sedang aktif.

3. Manajemen Model

setModelRoot(newRoot)method
Dipanggil setiap kali render selesai. Menghapus model lama (dan membuang memori geometrinya), lalu memasang model baru.
Fitur Spesial: Otomatis menyalakan castShadow dan receiveShadow ke semua mesh baru (jika mode Studio aktif), lalu membangun ulang cache untuk Measure Tool.
Dipanggil oleh:
doRender (main.js)

4. Section Plane & Measure Tool

Fitur interaksi langsung pada viewport 3D.

setSection({ enabled, axis, position, flipped })method
Menerapkan THREE.Plane ke material model (Local Clipping). Hanya memotong model CAD, tidak memotong Grid atau Overlay lain.
setMeasureMode(on)method
Mengaktifkan Raycaster saat kursor bergerak/klik di atas model. Menampilkan preview bola hijau saat hover.
_snapPoint(hitPoint, mouseX, mouseY, rect)private
Mencari vertex/edge/face terdekat dalam radius 20px di layar (Screen-Space Snapping). Memastikan pengukuran CAD sangat presisi tanpa harus zoom sedetail mungkin.

5. Overlays (Dimension & Wireframe)

toggleDimensions()method
Membuat/menghapus Bounding Box wireframe (biru) beserta garis ukur (X, Y, Z) dengan label Sprite yang selalu menghadap kamera.
toggleWireframe()method
Membuat overlay garis menggunakan EdgesGeometry(..., 15°). Hanya menampilkan garis luar (siluet), membuang garis diagonal pada permukaan datar.

6. Capture (PNG & GIF)

Fitur untuk menghasilkan gambar berkualitas tinggi tanpa harus melakukan Screen Recording.

captureScreenshot(scale)method
Membuat Offscreen Renderer sementara, merender scene, dan mengembalikan string DataURL (PNG). Resolusi bisa 2× atau 4× dari resolusi layar.
iterateTurntable({ frames, size, signal }, onFrame)async method
Memutar kamera 360° secara bertahap. Di setiap frame, ia memanggil onFrame(ImageData) yang kemudian dikirim ke encoder GIF (gifenc).
Dipanggil oleh:
app/capture.js (Turntable GIF)
