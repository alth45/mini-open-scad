Geometry, Manifold & CSG

Lapisan yang mengurus pembentukan mesh, operasi boolean (Watertight), dan ekstraksi 2D.

Arsitektur Baru: Mini OpenSCAD telah migrasi dari three-bvh-csg (JS) ke Manifold-3D (WebAssembly). Ini menjamin hasil boolean 100% watertight (siap 3D print). three-bvh-csg kini hanya berfungsi sebagai fallback.

1. Geometry Helpers (src/evaluator/geometry.js)

Kumpulan fungsi utilitas untuk manipulasi tipe data Three.js.

makeMesh(geometry)function
geometry: THREE.BufferGeometry → THREE.Mesh
Membungkus BufferGeometry menjadi Mesh dengan material standar (default color 0xf9d72c). Menyimpan properti userData.scad = true sebagai penanda.
Dipanggil oleh:
builtins.jsmanifold-engine.js
is2D(obj)function
obj: any → boolean
Mengecek apakah objek merupakan representasi 2D (__shape2d === true). Digunakan oleh evaluator untuk memisahkan alur 2D dan 3D.
collectWorldGeometries(obj)function
obj: Object3D → THREE.BufferGeometry[]
Mengekstrak seluruh BufferGeometry dari sebuah objek/group, lalu membakarnya (apply) ke koordinat dunia (World Space) berdasarkan matrixWorld.

2. Manifold Engine (src/evaluator/manifold-engine.js)

Engine WebAssembly yang menjadi tulang punggung operasi Boolean (CSG) yang bersih dan presisi.

initManifold()async function
() → Promise<WasmModule>
Menginisialisasi engine WebAssembly Manifold. Memuat file manifold.wasm dari folder public/. Fungsi ini idempoten dan aman dipanggil berkali-kali.
Dipanggil oleh:
eval-worker.jsmain.js
objToManifold(obj)function
obj: Object3D → Manifold
Konversi Mesh/Group Three.js menjadi instance Manifold. Penting: Fungsi ini memanggil updateMatrixWorld(true) agar posisi (translate/rotate) tidak hilang saat diproses.
Dipanggil oleh:
builtins.js (union/difference/intersection)
manifoldMeshToGeo(mesh)function
mesh: ManifoldMesh → THREE.BufferGeometry
Mengonversi hasil Manifold kembali ke Three.js BufferGeometry. Geometri diubah menjadi non-indexed agar shading-nya tajam (flat shading).
Dipanggil oleh:
builtins.js
2D Boolean Trick: Manifold tidak mendukung CSG 2D secara langsung. Di builtins.js, kita mengakalinya dengan cara: (1) Extrude shape 2D setipis 0.1mm, (2) Lakukan Boolean Manifold 3D, (3) Ekstrak garis luarnya (top-face) kembali menjadi 2D.

3. Mesh Utils (src/evaluator/mesh-utils.js)

Fungsi pembersih mesh (digunakan saat engine *fallback* ke three-bvh-csg).

cleanGeometry(geometry)function
geometry: BufferGeometry → BufferGeometry
Membersihkan geometri: menyatukan vertex yang bertumpuk (mergeVertices) dan membuang segitiga dengan luas 0 (degenerate). Sangat berguna untuk mencegah error pada eksportir STL/3MF.

4. CSG Fallback (src/evaluator/csg.js)

Implementasi CSG lama berbasis JavaScript. Hanya digunakan jika Manifold gagal dimuat (misal browser tidak mendukung WASM).

makeBrush(obj)function
obj: Object3D → CSG.Brush
Menggabungkan semua geometri dari object menjadi satu BufferGeometry, lalu membungkusnya sebagai Brush yang siap dioperasikan oleh three-bvh-csg.
csgApply(aBrush, bBrush, op)function
(Brush, Brush, CSG.SUBTRACTION|INTERSECTION|ADDITION) → Brush
Menjalankan operasi CSG (Subtract/Intersect/Add) menggunakan evaluator three-bvh-csg.
